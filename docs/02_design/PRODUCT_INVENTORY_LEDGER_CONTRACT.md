# 제품재고장 현재 조회 계약

- 버전: 1.0 / 기준일: 2026-09-14
- 기준 코드: e75fdc49872b03cc765207715d8bc118833cca9e 및 현재 조회 경로
- 분류: GLOBAL / ERP_DB_INTERNAL
- 코드 authority: `app/services/product_inventory_service.py`, `app/services/io_nlq.py`

## 범위와 조회 단위

제품재고장은 제품별 조회기간의 이월·입고·출고·재고 집계이다.
`group_basis`는 제조사(maker), 발주처(order), 매입처(purchase), 재고위치(stock)를
구분하며 제품과 선택 집계 기준을 함께 사용한다. 실재고/장부재고 조건도 보존한다.
제품수불현황의 개별 입출고 행 조회와 이 집계 조회는 별도 기능이다.
자연어 `inventory_movement`의 기간 생략은 현재월 1일부터 기준일까지이며,
명시 기간 해석은 [공식 기간정책](SIMS_AI_NLQ_기간정책_공식기준.md)을 따른다.

제조사·발주처·매입처 조건은 기존 제품 마스터 연결을 따른다.
`ven_nm`은 마스터 매입/발주처 명칭 조건이며 이를 임의 제조사 조건으로 합치지 않는다.
제품그룹·구분·분류와 보험코드 등은 공통 제품 필터를 재사용한다.

## 수량·금액

- 이월수량 = 이전 입고수량 - 이전 출고수량
- 재고수량 = 이월수량 + 기간 입고수량 - 기간 출고수량
- 입고/출고 단가 = 각 기간 금액 / 해당 수량의 기존 계산 경로
- 이월/재고 금액 = 수량 × 선택 단가, 기존 금액 반올림 helper 적용

음수 재고를 0으로 보정하지 않는다. 수량 0과 단가 부족 처리는 기존 helper를 따른다.
총평균단가는 이월에는 이전 매입금액/수량, 재고에는 이전+기간 매입금액/수량을 사용한다.
기준가는 제품 기준가, 현보험약가는 제품 현재 보험단가를 사용한다.

## 최종매입가와 계약단가 선택의 현재 제한

최종매입가 모드는 제품별 기준일까지의 기존 정상 매입 이력 가격을 우선하고,
매입 후보가 없을 때 기존 출고 가격 후보를 사용한다. 재고위치별 최신 가격이 아니다.
기존 미결·이동 구분 제외와 정렬을 유지한다. R230의 다차원 원가 상태와 다르다.

현재 `price_mode='cons'`는 화면 이름이 계약단가지만 제품 마스터 기준가 대체 경로다.
R070 적용처 계약가격을 연결한 완료 기능으로 설명하거나 가격 검증에 사용하지 않는다.
이는 확인된 구현 제한이며 본 문서 작업에서 산식이나 서비스를 변경하지 않는다.

## Snapshot·표·다운로드

출고빈도 등급은 승인 Snapshot/profile authority에서 연결하며 현재고 자체를 대체하지 않는다.
범위·등급이 지원되지 않거나 운영 기준이 준비되지 않으면 임의 자료로 대체하지 않는다.
표시 행수와 전체 결과는 구분한다. 공통 formatter·현재표·다운로드·회사격리는
[현재고·현재표 계약](SIMS_NLQ_CURRENT_STOCK_CURRENT_TABLE_CONTRACT.md)을 따른다.
제한된 원천 조회 결과를 전체 ERP 전수 자료라고 설명하지 않는다.
