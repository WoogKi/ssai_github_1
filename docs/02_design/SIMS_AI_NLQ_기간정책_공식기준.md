# SIMS AI NLQ 기간정책의 공식 기준

- 문서 상태: **확정**
- 확정일: **2026-08-11**
- 적용 대상: SIMS AI NLQ의 기간 해석 및 자동 기본기간 정책
- 기준 문서 위치: `docs/02_design/SIMS_AI_NLQ_기간정책_공식기준.md`

---

## 1. 목적

이 문서는 SIMS AI NLQ에서 사용자가 기간을 직접 지정하지 않거나 `오늘`, `당일`, `하루`, `8월`, `이번달`, `한달`, `최근 한달` 등 자연어로 기간을 표현했을 때 조회기간을 일관되게 해석하기 위한 **공식 공통 정책**을 정의한다.

이 정책은 특정 질문별 예외 규칙이 아니라, 관련 NLQ가 공통으로 재사용해야 하는 기간 계약이다.

## 2. 기간 해석 우선순위

```text
1. 사용자가 직접 명시한 기간
2. 사용자가 명시한 자연어 기간 표현
3. 기간 미지정 시 자동 기본기간
```

사용자가 기간을 직접 지정한 경우 자동 기본기간보다 항상 우선한다.

## 3. 당일 / 오늘 / 하루 / 최근 1일

다음 표현은 모두 **기준일 당일 하루**를 의미한다.

```text
오늘
당일
하루
최근 1일
```

기준일이 `2026-08-11`이면 `2026-08-11 ~ 2026-08-11`이다.

예시:
- 오늘 입고현황 → 2026-08-11 ~ 2026-08-11
- 당일 매출현황 → 2026-08-11 ~ 2026-08-11
- 하루 출고현황 → 2026-08-11 ~ 2026-08-11

## 4. 월 지정 / 이번달

월을 지정한 표현은 **달력상의 해당 월 전체**를 의미한다.

예: `8월`, `2026년 8월`, `이번달`, `이번 월`

기준일이 `2026-08-11`이어도 8월은 `2026-08-01 ~ 2026-08-31`로 해석한다. 현재일까지 자르지 않고 해당 월의 1일부터 말일까지를 기간으로 사용한다.

예시:
- 8월 입고현황 → 2026-08-01 ~ 2026-08-31
- 이번달 매출현황 → 2026-08-01 ~ 2026-08-31
- 2026년 8월 출고현황 → 2026-08-01 ~ 2026-08-31

## 5. 한달 / 최근 한달 / 최근 1개월

다음 표현은 **기준일을 포함한 최근 31일**로 정의한다.

```text
한달
최근 한달
최근 1개월
```

계산식:

```text
시작일 = 기준일 - 30일
종료일 = 기준일
```

기준일이 `2026-08-11`이면 `2026-07-12 ~ 2026-08-11`이다.

예시:
- 한달 입고현황 → 2026-07-12 ~ 2026-08-11
- 최근 한달 매출현황 → 2026-07-12 ~ 2026-08-11
- 최근 1개월 출고현황 → 2026-07-12 ~ 2026-08-11

## 6. 월과 한달은 다른 정책이다

```text
8월 / 이번달
= Calendar Month
= 해당 월 1일 ~ 말일

한달 / 최근 한달 / 최근 1개월
= Rolling 1 Month
= 기준일 - 30일 ~ 기준일
```

2026-08-11 기준:
- 8월 → 2026-08-01 ~ 2026-08-31
- 최근 한달 → 2026-07-12 ~ 2026-08-11

## 7. 기간 미지정 기본정책

### 7.1 기간 미지정 + 추가 조회조건 없음

기간을 지정하지 않았고 별도의 검색조건도 없다면 **오늘 하루**를 자동 적용한다.

2026-08-11 기준:
- 입고현황 → 2026-08-11 ~ 2026-08-11
- 출고현황 → 2026-08-11 ~ 2026-08-11
- 매출현황 → 2026-08-11 ~ 2026-08-11

공식 규칙:

```text
기간 미지정 + 추가조건 없음
→ 오늘 하루
```

### 7.2 기간 미지정 + 추가 조회조건 있음

기간은 지정하지 않았지만 제품, 거래처, 제조사, 매입처, 발주처, 재고위치, 통합검색 등 **사용자 조회조건이 하나 이상 있으면 최근 한달**을 자동 적용한다.

2026-08-11 기준: `2026-07-12 ~ 2026-08-11`

예시:
- 한미 입고현황 → 통합검색 한미 / 2026-07-12 ~ 2026-08-11
- 매입처 온라인팜 입고현황 → 매입처 온라인팜 / 2026-07-12 ~ 2026-08-11
- 제품 낙소졸 출고현황 → 제품 낙소졸 / 2026-07-12 ~ 2026-08-11

공식 규칙:

```text
기간 미지정 + 추가조건 있음
→ 오늘 포함 최근 한달(31일)
```

## 8. 명시기간 최우선

사용자가 기간을 직접 지정한 경우 자동 기본기간을 적용하지 않는다.

예시:
- 한미 입고현황 202608 → 2026-08-01 ~ 2026-08-31
- 온라인팜 입고현황 2026-08-01부터 2026-08-05까지 → 2026-08-01 ~ 2026-08-05
- 2025년 7월 매출현황 → 2025-07-01 ~ 2025-07-31

검색조건이 함께 있어도 사용자가 지정한 기간을 변경하지 않는다.

## 9. 최종 정책표

| 사용자 표현 또는 상태 | 공식 적용 기간 |
|---|---|
| 오늘 / 당일 / 하루 / 최근 1일 | 기준일 당일 |
| 8월 / 2026년 8월 | 해당 월 1일 ~ 말일 |
| 이번달 / 이번 월 | 현재 달 1일 ~ 말일 |
| 한달 / 최근 한달 / 최근 1개월 | 기준일 - 30일 ~ 기준일 |
| 기간 미지정 + 추가조건 없음 | 기준일 당일 |
| 기간 미지정 + 추가조건 있음 | 기준일 - 30일 ~ 기준일 |
| 명시기간 있음 | 사용자 명시기간 최우선 |

## 10. 프로그램 내부 canonical 정책명 권장

```text
today
calendar_month
rolling_1month
explicit_period
```

의미:
- `today` → 기준일 ~ 기준일
- `calendar_month` → 해당 월 1일 ~ 말일
- `rolling_1month` → 기준일 - 30일 ~ 기준일
- `explicit_period` → 사용자가 지정한 기간

기존 `current_month`와 `rolling_1month`를 동일 의미로 사용하지 않는다.

## 11. 조회조건 표시 원칙

사용자 화면에 표시되는 조회조건과 실제 실행기간은 반드시 일치해야 한다.

예시:

```text
입고현황
조회조건:
기간 2026-08-11
오늘 자동적용(추가 조건 없음)
```

```text
한미 입고현황
조회조건:
기간 2026-07-12 ~ 2026-08-11
통합검색 한미
최근 1개월 자동적용(통합검색 조건)
```

```text
8월 입고현황
조회조건:
기간 2026-08-01 ~ 2026-08-31
사용자 지정월
```

## 12. 공통 구현 원칙

1. 기간정책을 질문별 `if/elif` 예외로 구현하지 않는다.
2. 동일 기간정책은 공통 helper 또는 공통 metadata를 재사용한다.
3. 실제 실행 params, 기간정책, 조회조건 summary, case-log가 동일한 기간 의미를 사용한다.
4. 추가조건 여부는 실제 사용자 명시조건 metadata를 기준으로 판단한다.
5. Default 또는 내부 생성 params를 사용자 명시조건으로 추측하지 않는다.
6. 월 지정과 rolling 한달을 동일 정책으로 처리하지 않는다.
7. 사용자가 명시한 기간은 항상 자동 기본기간보다 우선한다.

## 13. 회귀 기준일 예시

기준일을 `2026-08-11`로 고정한 회귀에서 최소 다음을 보호한다.

```text
입고현황
→ 2026-08-11 ~ 2026-08-11

한미 입고현황
→ 2026-07-12 ~ 2026-08-11

8월 입고현황
→ 2026-08-01 ~ 2026-08-31

최근 한달 입고현황
→ 2026-07-12 ~ 2026-08-11

한미 입고현황 202608
→ 2026-08-01 ~ 2026-08-31
```

월말, 연말, 윤년 경계도 별도 회귀로 보호한다.

## 14. 최종 확정

> **기간 미지정 + 추가조건 없음 → 오늘 하루**  
> **기간 미지정 + 추가조건 있음 → 오늘 포함 최근 한달(31일)**  
> **오늘 / 당일 / 하루 / 최근 1일 → 오늘 하루**  
> **월 지정 / 이번달 → 해당 달 전체**  
> **한달 / 최근 한달 / 최근 1개월 → 오늘-30일 ~ 오늘**  
> **사용자 명시기간 → 항상 최우선**

이 문서를 이후 SIMS AI NLQ 기간 해석, 구현, 회귀테스트 및 Codex 작업지시의 공식 기준으로 사용한다.
