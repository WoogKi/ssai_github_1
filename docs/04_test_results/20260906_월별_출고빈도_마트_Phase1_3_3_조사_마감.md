## 3. 저장·승인 구조

- 월별 fact identity: 회사 + 기준월 + scope fingerprint + schema/algorithm version + generation
- 월별 fact grain: manifest + 제품 + 재고위치
- 보존 값: 정상 출고횟수, 출고수량, 출고일수, source diagnostics,
  product/scope/source fingerprint, checksum, watermark 상태와 provenance
- 승인 구조: immutable generation 생성 후 검증·승인·게시하며 동일 identity의
  CURRENT 승인 generation은 하나만 유지
- lifecycle authority: 회사 + scope + 제품 grain의 독립 immutable authority
- 월 manifest는 lifecycle manifest ID와 authority checksum을 참조

Phase 3의 최초 구조는 lifecycle 40,526행을 월 generation마다 반복 저장·조회해
persistence/approval/readback에 `629.838초`가 걸렸다. Phase 3.1에서 독립
lifecycle authority와 월 fact 최소 저장 구조로 분리한 뒤 같은 구간이
`9.014초`로 줄어 약 98.6% 개선됐다.

## 4. 신규품목 F와 lifecycle 품질

- 공식 `F` 기준은 최초 정상 입고월 `M0` 포함 3개월이다.
- `M0`, `M0+1`, `M0+2`는 `F`, `M0+3`부터 기존 `A~E/X`다.
- 제품 등록일과 최초출고일은 보조 근거이며 `F` 부여 기준으로 사용하지 않는다.
- 최초 정상 입고가 신뢰 불충분하면 `F`를 강제하지 않는다.
- lifecycle은 등록일 > 최초입고, 최초출고 < 최초입고, 등록 후 최초입고 장기
  gap을 `review_required` 품질 신호로 보존한다.
- 회사 4 `F=270`, 회사 6 `F=62`이며 기존 legacy `A~E/X` 값은 별도로 보존됐다.

## 6. Exact equality와 provenance

회사 4와 회사 6 모두 다음 비교를 PASS했다.

- direct 3개월 결과 vs 기존 승인 Snapshot
- monthly shadow 결과 vs direct 3개월 결과
- monthly shadow 결과 vs 기존 승인 Snapshot
- product key와 scope
- 월별 activity와 event count
- 기존 출고빈도등급 `A~E/X`
- checksum과 source fingerprint

회사 4 Snapshot checksum은
`6ce83990630b531a68f9ee1274c827ca97c0d6d52589e49d9a2eedecc94b5d20`,
회사 6은
`47c8e230060042a9a6d8fb9cd10dbb9da5765d9788397beb054890888d59176a`다.

양사 모두 신뢰 가능한 verified source watermark가 없다. 따라서
`source_watermark=null`, `source_watermark_status=unverified`를 그대로
보존한다. 동일 scope의 deterministic full fingerprint exact match는 CURRENT
증거로 사용하지만 `watermark_verified=false`를 유지한다. scope 또는
fingerprint가 다르면 STALE, 관측 증거가 없으면 UNVERIFIED다.

## 7. 성능 판단과 HOLD 이유

monthly core는 두 회사 모두 direct보다 빠른 방향이지만 절대 개선 폭은 회사 4
`0.655초`, 회사 6 `0.130초`로 작다. lifecycle preflight를 직렬로 포함하면
회사 4는 `14.056초`, 회사 6은 `3.332초`로 각각 direct보다 느리다.

따라서 최종 HOLD는 실패 판정이 아니다. 저장·승인 구조, `F`/lifecycle 계약과
direct 대비 exact equality는 모두 PASS했지만, 운영 reader 전환으로 얻는
실질적 성능 이득이 아직 충분히 입증되지 않았기 때문이다.
