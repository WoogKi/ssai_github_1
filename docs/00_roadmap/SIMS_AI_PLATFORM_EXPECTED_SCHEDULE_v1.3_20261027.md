## 병행 경계

- 10/30 준비와 11/1 마감 중 R210/R220, 미결 매출·2차 확정마감, Snapshot 알고리즘, LLM Runtime, 발주 산식을 바꾸지 않는다.
- MCP는 Phase 7과 별도의 4.x 트랙이다. 현재 Mock/로컬 STDIO 기술 PoC를 재사용하되 **실제 외부 연결은 이 문서의 승인만으로 실행하지 않는다**. [MCP 현황·다음 단계](../02_design/SIMS_AI_MCP_CURRENT_STATE_AND_NEXT_PHASE_20261027.md) 참조.
- 전체 Snapshot의 최근 3개월 R120 직접 계산은 현행 유지다. 월별 Fact의 10월 증분이 최종 Snapshot 전체의 1개월 증분을 뜻하지 않는다.
- Offline PASS, 회사별 DB Exact, 실제 화면 품질, GitHub Push, 2호기 설치·Smoke는 별도 Gate다. 일정 지연 시 P0 정확성 Gate를 줄이지 않는다.

**사용자 결정 필요:** 운영 회사 조회/마감 승인 범위, NLQ 미등록 3건, R210/R220 및 미결 매출 정책, 외부 MCP 서버·Resource·권한·키, ERP 실발주 쓰기, 2호기 배포.
