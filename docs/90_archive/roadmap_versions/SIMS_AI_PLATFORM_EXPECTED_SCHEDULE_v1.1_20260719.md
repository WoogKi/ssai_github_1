## 1. 일정 산정 원칙

이 일정은 다음 조건을 전제로 한다.

1. 사용자님과 ChatGPT/Codex가 현재와 같이 한 작업 단위씩 조사, 검토, 구현, 테스트한다.
2. 한 번에 대규모 변경을 하지 않고 조사→설계→구현→회귀→1·2호기 확인 순서를 유지한다.
3. Phase 4에서는 최소 핵심 facts를 먼저 검증하고 Dashboard Lite v0.1을 빠르게 보여준 뒤, 사용자 피드백으로 v0.2와 전체 facts를 구체화한다.
4. 1작업일은 집중 개발·검증이 가능한 하루를 의미한다.
5. 사용자 확인, 운영 DB 테스트, LM Studio 응답 대기, 1·2호기 배포시간은 별도 변동 요인이 될 수 있다.
6. 대한민국 공휴일, 사용자님의 다른 업무, 운영 긴급장애는 일정에서 제외한다.
7. 조사 결과에 따라 수정 파일이나 회귀 fixture가 예상보다 늘어나면 다음 작업 시작일을 조정한다.
8. 입금·출금·채권·채무 자료가 없으므로 DSO·DPO 등 자금 회전일은 이번 일정에서 제외한다.
9. 사용자 파일럿은 화면을 보고 이해한 내용, 실제로 취한 조치, 불필요한 알림, 누락된 예외를 기록한다.

- 운영 DB 부하를 줄이기 위한 갱신 시간대
- Validation 실패 시 Dashboard·ML 사용을 차단할지 경고만 표시할지

## 10. 일정 지연 가능성이 큰 요인

| 위험 | 영향 | 대응 |
|---|---|---|
| 실제 registry action 수 증가 | 08A·fixture 기간 증가 | action inventory를 먼저 고정 |
| KPI마다 서로 다른 payload | 공통 facts 구현 복잡도 증가 | 공통 계약+화면별 extension 분리 |
| 부분월 정의 불일치 | 예상·진척률 재설계 가능 | 시간 기준과 분자·분모 우선 확정 |
| ERP 회사별 schema 차이 | SQL·검증 범위 증가 | 회사별 schema baseline 관리 |
| 대형 DataFrame·채팅방 | 성능 최적화 기간 증가 | 구간별 timing과 memory 측정 |
| LM Studio 모델 변동 | 실제 LLM 품질·속도 변동 | 운영 모델 고정 후 예열 3회 측정 |
| 사용자 확인 대기 | 다음 Gate 시작 지연 | 작업별 확인 포인트를 한 번에 제시 |
| 재고수요 예측 오차 | 준비율과 알림 신뢰 하락 | 계산 기준일·예상식·신뢰도 표시, 예외 검토 |
| 역할별 기대 차이 | 화면·조치 규칙 재작업 | 파일럿을 경영·구매·영업 역할로 구분 |
| 과도한 알림 | 사용자 무시·불신 | 98% 침묵, 99% 해제, 반복 억제, 예외 우선순위 |
| 운영 긴급장애 | 계획 작업 중단 | 안정화 브랜치·회귀 기준선 보존 |

## 11. 권장 주간 운영 방식

| 시점 | 권장 작업 |
|---|---|
| 작업 시작 | Git 상태, 브랜치, 기준 커밋, AGENTS.md 확인 |
| 조사 종료 | 수정 없이 조사 보고와 구현 후보 제출 |
| 구현 승인 후 | 한 작업지시 단위로 코드·fixture 수정 |
| 로컬 검증 | 대상 회귀, 전체 회귀, `git diff --check` |
| 사용자 화면 검증 | 실제 조건, 화면표, Excel, LLM 답변 확인 |
| 배포 | 1호기 commit/push 후 2호기 pull·재시작 |
| 주간 마감 | 완료·보류·다음 작업과 기준 커밋 기록 |

## 12. 현재 바로 시작할 작업

현재 즉시 시작할 작업은 읽기 전용 `08A-Quick 핵심 숫자·근거 조사`다. 기존 전수조사 항목을 버리지 않고 Dashboard Lite v0.1에 필요한 지표를 먼저 확정한다.

08A 완료 전에는 다음을 하지 않는다.

- 분석/KPI prompt 확대
- Dashboard Lite 또는 공통 facts payload 구현
- SQL 또는 DB 변경
- 회귀 fixture 변경
- commit·push
- Phase 4.5 DDL 설계 착수

08A-Quick 조사 결과를 사용자님이 확인한 뒤 Dashboard Lite v0.1 설계로 진행한다. 첫 시연 후에는 사용자 파일럿을 거쳐 v0.2를 구체화하고, 그다음 전체 facts 계약과 회귀를 완결한다.
