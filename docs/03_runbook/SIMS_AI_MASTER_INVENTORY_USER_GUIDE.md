## 마스터 정보

거래처는 코드와 명칭으로 식별한다. 제조사(제약사), 매입처, 발주처는 역할이 다르며
명칭이 비슷하다고 같은 거래처로 확정하지 않는다. 복수 후보는 확인 후 조회한다.
회사별 코드명은 현재 선택 회사의 자료를 사용한다.

제품은 제품코드를 기준으로 제품명, 규격, 보험코드, 바코드와 제조사를 확인한다.
제품그룹, 제품구분, 제품분류는 서로 다른 조건이다. 제품 사용여부와 추가·수정
담당자 및 날짜는 기존 자료를 조회하는 조건이며, 화면에서 ERP 자료를 수정하는 기능이 아니다.
제품 마스터 상세와 Snapshot 기반 제품정보는 목적과 기준 시점이 다르다.

## 적용처와 재고위치

단가적용처는 계약가격 적용 대상, 재고적용처는 재고 관련 적용 대상이다.
두 필드는 독립적으로 보존하며 제조사나 대표매입처로 대신하지 않는다.
재고위치는 재고가 속한 위치 조건으로, 재고적용처와도 다르다.
발주 계산에서 미지정 기본 코드는 단가적용처 50002, 재고적용처 50001이다.
사용자의 명시 코드가 우선하고 이름은 회사별 코드명 자료로 표시한다.
이 기본값을 다른 모든 조회 기능의 기본값으로 확대하지 않는다.

## 가격 조회

최종 계약단가는 기준일에 적용할 수 있는 계약 중 최신 시작일의 계약을 조회한다.
계약 이력 조회의 시작일 범위와 기준일 현재 계약 조회는 같은 뜻이 아니다.
매입단가 조회에는 한 제품의 거래처·위치·적용처별 여러 원가 상태가 나타날 수 있다.
여러 행을 임의로 평균하거나 하나를 골라 최종 가격이라고 설명하지 않는다.
발주 계산의 가격 우선순위는 별도 발주 업무 계약을 따른다.

## 제품재고장과 제품정보

제품재고장은 조회기간의 이월, 입고, 출고와 재고 흐름을 집계한다.
제조사·발주처·매입처·재고위치 집계 기준을 구분한다.
현재 구현에서 제품재고장의 '계약단가' 선택은 제품 기준가 대체 경로이므로,
실제 적용처 계약가격 확인에는 계약단가 조회를 사용한다.

Snapshot 기반 제품정보는 승인된 운영 기준의 출고빈도·수명주기·통계를 제공한다.
신규 제품 등급 F는 증가추세라는 뜻이 아니다. 자료부족·오래된 가격은 확정값으로
설명하지 않는다. 운영 기준이 준비되지 않았다고 자동 재생성하지 않는다.
현재고는 실제 조회 기준을 따르며 음수를 임의로 0으로 바꾸지 않는다.
